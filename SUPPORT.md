# Support

This file applies to each repository of the `gsuquet` account that has no `SUPPORT.md` of its own.

The repositories are personal projects. They have no support contract and no fixed response time.

## Get help

1. Read the `README.md` and the documentation of the repository.
2. Search the issues of the repository for the same problem or question.
3. If no issue has it, open an issue. Tell the command that you ran, the output and the result that you expected.

## Do not use issues for these subjects

- A vulnerability. Obey the [security policy](SECURITY.md).
- A problem with a person's behavior. Obey the [code of conduct](CODE_OF_CONDUCT.md).
